# Original Idea

The Markdown files in my Obsidian vault are in a sorry state, with numerous violations of style and formatting rules.

I need a command-line interface (CLI) application that can detect, list, and automatically fix violations of Markdown style and formatting rules.

The application will be named `machdown`, written in Rust for speed and reliability, and will check/fix the rules listed here:

<https://github.com/markdownlint/markdownlint/blob/main/docs/RULES.md>
